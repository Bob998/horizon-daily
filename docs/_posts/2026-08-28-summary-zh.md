## [Cloudflare 通过优化 1.1.1.1 DNS 缓存节省 100TB 内存](https://blog.cloudflare.com/dns-cache-memory-optimization-1111/) ⭐️ 5.0/10

Cloudflare 工程师详细介绍了对其 1.1.1.1 解析器 DNS 缓存布局的五项 Rust 级内存优化，将每条目的内存占用减少了 56%，并在其整个服务器群中释放了约 100TB 的内存。这些更改影响了 1.1.1.1、Gateway DNS、DNS Firewall 和 AS112 等服务。 这一优化显著降低了 Cloudflare 的运营成本，因为内存是运行全球 DNS 基础设施的主要开支。它也展示了系统级编程在提高效率和可扩展性方面的重要性，这对关注基础设施创新的投资者和技术爱好者具有参考价值。 这些优化包括将每条目的内存占用减少 50%以上，在超过 2500 亿条 DNS 缓存条目的规模下，相当于节省了 100TB 内存。这些更改是用 Rust 实现的，突显了该语言的性能和安全性特点。

hackernews · TangerineDream · Aug 27, 17:17 · [社区讨论](https://news.ycombinator.com/item?id=49468083)

**背景**: 1.1.1.1 是 Cloudflare 运营的公共 DNS 解析器，以速度和隐私著称。DNS 缓存存储查询结果以减少延迟和上游流量，但在大规模下，内存使用成为显著成本。Cloudflare 的优化工作是持续基础设施改进的一部分，旨在保持性能的同时控制开支。

## [PayPal 应用封禁 GrapheneOS 用户，引发变通方案讨论](https://news.ycombinator.com/item?id=49462253) ⭐️ 5.0/10

PayPal 的安卓应用现在在 GrapheneOS 上崩溃，抛出 RootDetectionSecurityException，阻止用户使用该应用。问题似乎由应用的反 root 检测触发，该检测将 GrapheneOS 标记为已 root。 此事意义重大，因为 GrapheneOS 是一个注重隐私的操作系统，用户群不断增长，PayPal 的封禁可能会疏远注重安全的用户。这也凸显了应用安全措施与替代安卓发行版之间的紧张关系，可能影响隐私倡导者对金融科技应用的采用。 崩溃由 RootDetectionSecurityException 引起，表明 PayPal 的应用检测到了它认为的 root 权限。一些用户报告称，在 GrapheneOS 设置中禁用“安全应用生成”可暂时解决问题，而其他用户通过调整漏洞利用保护设置成功解决。

hackernews · leumon · Aug 27, 09:56

**背景**: GrapheneOS 是一个开源、强化安全的基于安卓的操作系统，专为 Pixel 设备设计，截至 2026 年 4 月约有 40 万活跃用户。Root 检测是银行和支付应用中常见的防欺诈安全机制，但常常误报 GrapheneOS 等自定义 ROM 为已 root，尽管它们并未 root。PayPal 的封禁是应用限制替代安卓发行版这一更广泛趋势的一部分，尽管 GrapheneOS 具有强大的安全性能。
