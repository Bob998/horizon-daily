## [币安据报遭 56 亿美元黑客攻击，SAFU 保险基金耗尽](https://arkm.com/explorer/entity/21a94755-f604-45e5-9501-6542e23005e8) ⭐️ 9.0/10

## [PHP2Shell 与 Linux XFRM 漏洞链攻击攻陷 25 台服务器，含美国政府系统](https://dreamgroup.com/blog/chained-php2shell-exploit-roots-25-servers) ⭐️ 6.0/10

一个将 PHP2Shell PHP 远程代码执行漏洞（CVE-2026-109618 和 CVE-2026-109619）与 Linux 内核 XFRM ESP-in-TCP 提权漏洞（CVE-2026-46300，代号“Fragnesia”）结合的攻击链，据称攻陷了 25 台服务器，其中包括美国政府所属系统。该事件由 Dream 公司在一篇博客文章中披露，该公司由奥地利前总理塞巴斯蒂安·库尔茨创立。 美国政府服务器通过开源漏洞链被攻陷，凸显了默认启用的内核攻击面带来的系统性风险，可能促使联邦和企业加快在补丁管理、内核加固和终端检测方面的支出。同时，这也引发了对防火墙和安全设备厂商问责的讨论，因为这些厂商的配置可能助长了攻击。 PHP2Shell 漏洞影响 PHP 5.4 至 8.5 版本，允许未经认证的远程代码执行；而 XFRM ESP-in-TCP 漏洞是一个本地提权漏洞，已有公开的概念验证代码且不涉及竞争条件，这意味着针对早期“Dirty Frag”漏洞的补丁无法缓解该漏洞。社区分析认为，根据报告中逐字引用的 PAN-OS 设置和 SELinux 配置，涉及的防火墙厂商可能是 Palo Alto Networks。

hackernews · 882542F3884314B · Oct 29, 10:42 · [社区讨论](https://news.ycombinator.com/item?id=50286987)

**背景**: PHP2Shell 指的是 PHP 中的两个严重内存安全漏洞，可导致 Web 服务器被远程代码执行。Linux 内核的 XFRM 子系统负责处理 IPsec 转换，而 ESP-in-TCP 功能允许 IPsec 数据包穿越 NAT 设备；该领域的漏洞可让本地攻击者提升至 root 权限。将面向 Web 的远程代码执行与本地提权结合是一种常见的攻击模式，可将单个服务被攻陷转变为整个服务器被接管。
