## [美联储公布 2026 年 8 月至 9 月贴现率会议纪要](https://www.federalreserve.gov/newsevents/pressreleases/monetary20261013a.htm) ⭐️ 7.0/10

美联储理事会于周二公布了其审查并确定通过贴现窗口向存款机构提供的贴现率的会议纪要，涵盖 2026 年 8 月 17 日、9 月 9 日和 9 月 16 日举行的理事会会议。 这份纪要提供了了解美联储内部贷款利率讨论的一手窗口，可影响市场对政策利率路径、美国国债收益率及整体风险情绪的预期。尽管贴现率纪要通常不如 FOMC 声明或纪要那样能引发市场大幅波动，但它仍能释放美联储政策立场的信号。 贴现率由各储备银行的董事会制定，并须经美联储理事会审查和确定；自 2003 年 1 月 9 日起生效的贴现窗口计划中，主要信贷利率即为所收取的利率。本次纪要涵盖三次会议，此外美联储自 2026 年 7 月 1 日起对贴现窗口贷款实施了更新的抵押品保证金安排。

rss · Federal Reserve Press Releases · Oct 13, 18:00

**背景**: 贴现窗口是美联储的贷款工具，允许存款机构在无法从市场上其他银行获得资金时借入资金。贴现率就是对这些贷款收取的利率，通常设定在联邦基金利率之上，以抑制常规借款。美联储定期公布理事会贴现率会议纪要，这与更受市场关注的、记录联邦基金目标利率货币政策讨论的 FOMC 纪要有所不同。

## [英国人均发电量降至 20 世纪 70 年代水平](https://ourworldindata.org/data-insights/electricity-generation-per-person-in-the-united-kingdom-has-fallen-by-a-third-from-its-early-2000s-peak) ⭐️ 5.0/10

**背景**: 人均发电量是总发电量除以人口，常被用作工业活动和居民生活水平的粗略指标。英国电力需求在 2005 年左右达到峰值，此后因能效提高、制造业向服务业转移以及通过互联线路从法国等欧洲国家进口增加而下降。英国国家电网电力系统运营商（National Grid ESO）因低估电动汽车和热泵带来的未来需求增长而受到批评。

## [AWS 推出 Lambda Web Functions，原生支持 Web 应用托管](https://aws.amazon.com/blogs/aws/announcing-aws-lambda-web-functions-for-fast-consistent-web-app-performance-anywhere/) ⭐️ 5.0/10

AWS 宣布推出 AWS Lambda Web Functions，这是一种新的无服务器计算原语，可在 Lambda 上原生运行 HTTP 框架，通过多并发执行和自动化全球分发提供快速、一致的响应。此次发布旨在让开发者用更标准的框架在 Lambda 上运行 Web 应用，被直接拿来与 Cloudflare Workers 和 serverless-express 进行比较。 这增强了 AWS 在无服务器和边缘计算市场的竞争地位，而 Cloudflare Workers 一直通过让 Web 应用部署更简单、更熟悉来赢得开发者青睐。对于关注云基础设施的投资者和企业而言，这表明无服务器平台正持续向标准 Web 框架靠拢，可能降低迁移摩擦并扩大 Lambda 可承载的工作负载范围。 Lambda Web Functions 支持多并发执行和自动化全球分发，这使其区别于传统的 Lambda 函数——后者是无状态、短生命周期（最长 15 分钟）、事件驱动且由开发者编写处理程序的。AWS 还通过 Serverless Land 发布了实用指南和代码示例，而社区成员指出，类似功能此前可通过 Node.js 的 serverless-express 以及 Rust 的 axum-aws-lambda 中间件实现。

**背景**: AWS Lambda 是亚马逊的无服务器计算服务，让开发者无需配置或管理服务器即可运行代码，传统上采用事件驱动模型，由处理函数响应触发器。Cloudflare Workers 是竞争性的无服务器平台，在 Cloudflare 的边缘网络上运行代码，可从零自动扩展到数百万请求，并提供免费套餐。serverless-express 是一个开源库，让开发者能在 Lambda 和 API Gateway 之上运行 Express 等 Node.js 框架，实际上在此次 AWS 原生方案推出之前就已实现无服务器基础设施上的 Web 应用。
